# 회의 액션아이템 정리기

회의록을 붙여 넣으면 **할 일 · 담당 · 기한**을 뽑아 주는 업무 도구입니다.
핑거 AX 해커톤 2차 접수 흐름을 점검하려고 만든 **테스트(TEST) 프로젝트**입니다.

- 한 줄 소개: 내 업무에서 회의록의 액션아이템 정리를 해 주는 서비스
- 판단 지점: 담당자 · 기한이 비었거나 애매한 항목은 「확인 필요」로 남기고 사람이 정한다
- 사용 도구: Claude Code, GitHub, Vercel

## 쓰는 법

1. 「샘플 회의록 넣기」 또는 회의록 붙여 넣기
2. 「액션아이템 뽑기」
3. 비어 있는 담당 · 기한을 직접 채우고 「확정」 체크
4. 「메시지로 복사」로 메신저에 공유

입력은 브라우저 안에서만 처리합니다. 서버 · 외부 API 호출과 실제 발송은 없습니다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` · `style.css` | 화면 |
| `app.js` | 버튼 · 표 · 복사 |
| `parser.js` | 액션아이템 추출 규칙 (`@담당`, `담당:`, `기한:`, `10/25`, `10월 25일`, `다음 주 화요일` …) |
| `parser.test.js` | 규칙 테스트 — `npm test` |

정적 사이트라 빌드 없이 Vercel 에 그대로 배포됩니다.
